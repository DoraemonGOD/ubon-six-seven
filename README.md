# UBON Flood Link

แพลตฟอร์มประสานความช่วยเหลือน้ำท่วมจังหวัดอุบลราชธานี เชื่อมคนที่เดือดร้อนเข้ากับผู้ประสานและอาสาสมัคร ผ่านคำร้อง แผนที่ และคิวงาน

> ไม่ใช่หน่วยกู้ภัย หากอันตรายถึงชีวิต โทร 1784 (ปภ.) หรือ 1669 (การแพทย์ฉุกเฉิน)

## ทำอะไรได้

- ประชาชนส่งคำร้องขอความช่วยเหลือได้ทันทีโดยไม่ต้องสมัคร และติดตามสถานะด้วยเลข UBN
- ผู้ประสานตรวจคำร้อง จัดลำดับความเร่งด่วน และมอบงานให้อาสา
- อาสาสมัครและนักศึกษาสมัคร รอแอดมินยืนยัน แล้วรับงานในพื้นที่ของตัวเอง
- แผนที่ 25 อำเภอ ระบายสีตามระดับสถานการณ์ พร้อมศูนย์พักพิงและสิ่งของที่ยังขาด
- ห้องข่าวกรองสำหรับแอดมินและอาสาที่ยืนยันแล้ว ตรวจรายงาน รวมเรื่องซ้ำ และบันทึกทุกการกระทำ

ข้อมูลทั้งหมดเก็บบนเซิร์ฟเวอร์ ทุกเครื่องเห็นชุดเดียวกัน และทุกการแก้ไขตรวจสิทธิ์บนเซิร์ฟเวอร์ เบอร์โทรของผู้แจ้งเห็นเฉพาะผู้ประสานและอาสาที่รับงานนั้น

## เทคโนโลยี

TanStack Start (React 19) · Tailwind CSS 4 · Leaflet · PostgreSQL (Supabase) · Vercel

## เปิดบนเครื่อง

```bash
npm install
npm run dev
# http://localhost:8080
```

ถ้าไม่ตั้ง `DATABASE_URL` ระบบใช้ฐานข้อมูลชั่วคราวในเครื่อง (PGlite) พร้อมข้อมูลตัวอย่าง

บัญชีตัวอย่าง: อาสา `0815550101` / `demo1234` · แอดมิน `ubon-admin`

## ขึ้นเว็บจริง

ดูขั้นตอนใน `อ่านก่อนทำต่อ.txt` ต้องตั้ง `DATABASE_URL` และ `ADMIN_CODE` บน Vercel

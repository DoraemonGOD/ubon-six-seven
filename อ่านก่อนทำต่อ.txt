UBON Six Seven
แพลตฟอร์มประสานน้ำท่วมอุบลราชธานี

วิธีเปิดบนเครื่องตัวเอง
1. ติดตั้ง Node.js 22 ขึ้นไป
2. เปิดโฟลเดอร์นี้แล้วรัน
   npm install
   npm run dev
3. เปิดเบราว์เซอร์ที่ http://localhost:8080

บัญชีเดโม่
- อาสา: เบอร์ 0815550101 รหัส demo1234
- แอดมิน: ubon-admin (เปลี่ยนได้ด้วยตัวแปร ADMIN_CODE ดูด้านล่าง)

ข้อมูลเก็บที่ไหน
- คำร้อง รายงาน อาสา และงานที่มอบ เก็บบนเซิร์ฟเวอร์แล้ว ทุกเครื่องเห็นชุดเดียวกัน
  หน้าเว็บดึงข้อมูลใหม่ทุก 5 วินาที
- ทุกการแก้ไขตรวจสิทธิ์บนเซิร์ฟเวอร์ (src/lib/ops/ops.server.ts)
  ประชาชนไม่เห็นเบอร์โทรของคนอื่น อาสาเห็นเบอร์เฉพาะงานที่ตัวเองรับ
- รหัสผ่านเก็บเป็นแฮช ไม่ถูกส่งไปที่เบราว์เซอร์

ขึ้นเว็บจริง (Vercel + Supabase)
ฐานข้อมูล Supabase โปรเจกต์ UBUfloods สร้างตารางของแอปไว้ให้แล้ว (intel_*, ufc_*)
และล็อกไม่ให้ anon/authenticated อ่านได้

1. เอาโฟลเดอร์นี้ขึ้น GitHub เป็น repo ใหม่ (ไม่ต้องเอา node_modules)
2. vercel.com > Add New > Project > Import repo นั้น
   Framework Preset: Other  (Build/Output ปล่อยค่าเดิม)
3. ใส่ Environment Variables ก่อนกด Deploy
   - DATABASE_URL = Supabase > ปุ่ม Connect (บนสุดของโปรเจกต์) > แท็บ Connection String
       เลือก "Transaction pooler" (พอร์ต 6543) คัดลอก URI แล้วแทน [YOUR-PASSWORD]
       ด้วยรหัสผ่านฐานข้อมูล (ลืมรหัส: Project Settings > Database > Reset database password)
   - ADMIN_CODE   = รหัสแอดมินของจริง ตั้งเองให้เดายาก
4. กด Deploy รอ 1-2 นาที ได้ลิงก์ .vercel.app
5. เปิดลิงก์ ลองส่งคำร้องจากมือถือ แล้วเข้าแอดมินจากคอม ต้องเห็นคำร้องเดียวกัน

ข้อควรรู้
- ถ้าไม่ตั้ง DATABASE_URL ระบบจะใช้ฐานชั่วคราว ข้อมูลหายและแต่ละเครื่องไม่ตรงกัน
- ADMIN_CODE ต้องตั้งก่อนเปิดเว็บครั้งแรก เพราะบัญชีแอดมินถูกสร้างตอนเปิดครั้งแรก
  ถ้าเปลี่ยนทีหลัง ต้องลบแถว mem-admin ในตาราง intel_member แล้วเปิดเว็บใหม่
- เชื่อม Supabase แบบเข้ารหัส TLS อยู่แล้ว ถ้าใช้ Postgres ในเครื่องให้ตั้ง DATABASE_SSL=disable
- ตอน build ระบบรัน migration ที่ยังไม่เคยรันให้เอง (npm run db:migrate)

โครงสร้างที่ควรแก้
- src/routes          หน้าเว็บ
- src/components      ส่วนที่ใช้ร่วม
- src/lib/store.ts    ตัวเชื่อมหน้าเว็บกับเซิร์ฟเวอร์
- src/lib/ops         กติกาข้อมูลกลาง (engine.ts) และการตรวจสิทธิ์ (ops.server.ts)
- src/lib/intel       ห้องข่าวกรอง ตรวจสิทธิ์บนเซิร์ฟเวอร์
- migrations          ตารางฐานข้อมูล

คำสั่งตรวจ
- npm test        ทดสอบกติกา
- npm run typecheck
- npm run lint

หมายเหตุ
- อย่าอัปโหลดรหัสผ่านหรือ connection string ขึ้นที่สาธารณะ
- ระบบแนะนำหมวดในห้องข่าวกรองใช้การจับคำสำคัญ ไม่ใช่ AI และให้คนตรวจซ้ำทุกครั้ง
